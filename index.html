Powerful Features

🔢

Scimat - Mathematics

Comprehensive mathematical operations library

  • Trigonometry (sin, cos, tan, arc)
  • Logarithms & Exponentials
  • Number Theory (GCD, LCM, Prime)
  • Distance Calculations
  • 40+ Functions

Parse - Type Conversion

Safe and flexible parsing utilities

  • Optional-based parsing
  • Hex & Binary support
  • Array parsing
  • Boolean with flexible input

Http - Web Requests

Lightweight HTTP client for APIs

  • Response handling

Quick Examples

Example.java 
import CRJLib.Std;

public class Example {
    public static void main(String[] args) {
        Std std = new Std();

        // Mathematics
        double result = std.sim.squareRoot(25);
        long factorial = std.sim.factorial(5);
        boolean isPrime = std.sim.isPrime(17);

        // Parsing with safety
        int num = std.pars.toInt("123", 0);
        Optional<Integer> safe = std.pars.tryParseInt("abc");

        // HTTP requests
        HttpResponse response = std.http.get("https://api.example.com");
        if (response.isSuccess()) {
            std.coutln(response.getBody());
        }

        // Validation
        boolean valid = std.valid.isValidEmail("user@example.com");
        boolean strong = std.valid.isStrongPassword("MyP@ssw0rd!");

        // Encoding
        String encoded = std.codec.toBase64("secret");
        String hex = std.codec.toHex("data");
    }
}

Installation

1. Clone the Repository

git clone https://github.com/cjremillard/CRJLib.git
cd CRJLib

2. Build with Maven

mvn clean install

3. Add to Your Project

Add this dependency to your pom.xml:

<dependency>
  <groupId>com.cjremillard</groupId>
  <artifactId>crjlib</artifactId>
  <version>2.0.0</version>
</dependency>
